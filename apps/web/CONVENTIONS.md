# Web 组件开发规范

本文档约束 `apps/web` 的组件开发方式 保持代码一致可读 新成员可直接上手

## 目录职责

```text
src/
  app/            路由页面 每页一个目录 只做页面编排
  components/     跨页面复用组件 每组件一个文件
  lib/            纯逻辑模块 api 客户端 SSE 归约器 类型
test/             与 src 同构的测试目录
```

## 组件约定

1. 组件文件使用 PascalCase 命名 与导出名一致
2. 页面组件默认导出 其余组件具名导出
3. 使用服务端能力的组件保持默认 服务端渲染 需要 state 或浏览器 API 的组件
   顶部标注 `'use client'` 且只标注真正需要的一层
4. props 显式声明类型 禁止透传任意 props 对象
5. 组件内部不直接调用 fetch 一律通过 `lib/api` 客户端
6. 事件订阅与定时器在 useEffect 中建立与销毁 不得泄漏

## 状态管理

1. 服务端事件是唯一事实来源 视图状态由 `lib/runReducer` 从事件归约得出
2. 组件本地 state 只放输入框内容 加载标记这类瞬时交互状态
3. 禁止把接口返回复制进 state 再手动同步 轮询或 SSE 到达后整体归约
4. SSE 重连由浏览器 EventSource 自动完成 序号去重在归约器内完成

## 样式约定

1. 使用 Tailwind 原子类 不写自定义 CSS 类 特例样式集中在 globals.css
2. 颜色使用 slate 系为底色 状态色固定 emerald 成功 red 失败 amber 等待 sky 进行中 purple 升级
3. 中文文案与界面同语言 金额展示统一走 `formatAmount` 分转元

## 可用性约定

1. 所有按钮在请求进行期间禁用 防止重复提交
2. 空状态必须有可见提示 不允许空白区域
3. 错误信息展示在后端返回的 message 不自行猜测原因
4. 表格在移动端允许横向滚动 关键操作按钮不与时间线重叠
