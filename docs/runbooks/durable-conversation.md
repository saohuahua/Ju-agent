# 持久普通会话演示

本入口使用正式 HTTP 路由 客户页面和原事件流 通过 P6 持久任务与 P7 模拟网关处理普通查询
模型为确定性本地替身 不是实际大模型 费用明确为模拟零价 不读取环境密钥

## 启动

在仓库根目录确认 8787 没有被其他 API 占用后运行

```powershell
pnpm --config.verify-deps-before-run=false --filter @aftersales/api demo:durable
pnpm --config.verify-deps-before-run=false --filter web dev --hostname 127.0.0.1
```

本环境 pnpm 会因 package scripts 改动尝试自动安装 此处仅关闭运行前依赖核对 使用现有依赖
没有安装新依赖或修改依赖锁定版本

打开 http://127.0.0.1:8790/workbench 选择客户张伟
页面会明确显示持久只读模拟会话
先输入帮我查询订单 再按补问输入 SO-2026-0003
会话从处理中变为等待补充 再变为完成

数据单独保存在 data/durable-demo.db 原 data/desk-demo.db 不覆盖
重复启动保留已有记录 模型替身根据持久消息选择响应 不依赖内存脚本游标

## 接口与幂等

POST /api/runs 与 POST /api/runs/:runId/messages 在本模式中要求 Idempotency-Key
返回 202 前运行 命令 任务和客户消息均已在同一事务提交
同一客户同键同正文返回相同标识 同键异参返回 409
客户页面为同一失败草稿保留请求键 再点发送不会创建第二条命令
跨身份或切换会话后清理旧提交状态

补问回复绑定原 ask_user 调用标识 原配置从首条命令恢复 不从当前默认配置重新选择
旧会话不能通过续聊隐式迁移到该模式
持久会话拒绝旧通用恢复与主动物流注入入口 防止两个循环同时驱动同一个运行

## 恢复语义

完整模型轮次确认后才写 agent.turn 与 message.completed 不把流中半段文本发布为已完成内容
各只读结果与工具记录分别原子确认 恢复跳过已确认结果
只读调用成功但结果尚未提交时可能重新查询 不保证外部只读请求只发生一次

模型已返回但轮次未提交时可能再次调用模型 两次均独立计入 P7 账本
未确认用量继续保留 held 或 unknown 不因进程重启自动免费
提交始终校验 P6 所有者与代次 取消或超时后的迟到结果不能写回
会话暂停或结束与任务完成同事务提交 不残留阻挡后续消息的半完成任务

## 迁移边界

本模式支持 get_order get_shipment search_policy ask_user conclude escalate
政策检索采用零成本关键词基线 知识内容摘要不匹配原快照时拒绝使用新语料冒充旧版本
资金动作不可从这条路径发出 演示中的退款补偿价保等请求转人工
普通会话 Worker 只认领 conversation 管线 不抢占资金任务

这是显式开启的迁移通道 没有把旧 AgentRunner 的所有业务路径替换成新循环
复用现有模型协议 工具定义和事件上下文 以原子确认边界逐步迁移
旧资金路径暂时保留 在后续完成审批映射和执行互斥后再统一执行通道

本轮不是全渠道生产发布 真实模型传输 所有付費用途 资金自动执行 Docker 多机部署仍待原计划后续验证
