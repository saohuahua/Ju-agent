# 本机真实模型对话

此入口只把客户对话的模型传输改为真实服务。订单、退款和支付渠道仍为本机模拟；真实模型可能产生供应商费用。历史会话冻结原模型配置，启用后需新建会话。

## 配置

在本机打开 `http://127.0.0.1:8790/settings`，切换到主管身份。若前端自动避让了端口，以启动终端打印的地址为准。局域网地址如 `10.10.12.25` 不开放真实模型设置或付费对话。

API 启动终端会打印一次本机模型管理口令。设置弹窗依次填写接口协议、Base URL、提供商模型 ID、API Key、输入与输出每百万 token 的人民币估算价格，以及管理口令。支持 Anthropic Messages 和 OpenAI 兼容 Chat Completions。Base URL 必须使用 HTTPS；本机测试服务可用 HTTP 回环地址。

先点击“测试连接”，得到模型文本及用量确认后，才能点击“保存并启用”。测试会发起一次最多 32 输出 token 的真实调用，也可能计费。保存后同一浏览器会话保留管理口令，切换到客户身份并新建咨询，即可用真实模型对话。订单和资金仍是模拟；其他浏览器和局域网设备不会自动使用真实模型。

API Key 不会出现在状态响应、会话快照或数据库中，也不写入浏览器存储。重启 API 后，页面填写的 Key 失效；可重新输入，或在启动 API 的进程环境中设置 `ANTHROPIC_API_KEY` 或 `OPENAI_API_KEY`。环境变量本身不会自动启用真实模型，仍需在设置页测试并保存。也可以用 `MODEL_LOCAL_TOKEN` 固定管理口令；不配置时每次启动随机生成。

本机运行 `pnpm dev:offline` 时，启动脚本读取项目根目录 `.env`，并以其中的模型协议、地址、模型、Key 和估算单价为准。设置弹窗会预填非敏感字段；Key 不回传浏览器，只显示已配置。先从 API 启动终端取得本机管理口令，再点击“测试连接”和“保存并启用”，然后新建客户咨询。前端的 `/api` 代理指向当前启动的本机 API 端口。修改 `.env` 后需重启服务，旧会话仍使用原冻结模型快照。

本机需要启动后直接使用 `.env` 的真实模型时，设置 `MODEL_AUTO_ENABLE=1`，并填写有效的协议、地址、模型、Key 和两项费用估算单价。缺项会让 API 启动失败，不会退回模拟模型。开启后本机客户页面新建咨询直接使用真实模型；主管修改或停用模型仍需管理口令。连接状态受供应商服务影响，自动启用只表示已选择真实传输，不保证供应商当时可用。关闭开关并重启可恢复默认离线模型入口。

Gemini 官方 OpenAI 兼容接口可使用 `https://generativelanguage.googleapis.com/v1beta/openai/`。当前本机配置的费用单价 3 元与 20 元每百万 token 只是保守估算，不等于 Google 账单；[Google 官方价格页](https://ai.google.dev/gemini-api/docs/pricing)以美元列价，使用前应按自己的计费档位和汇率核对。供应商返回 503 时，模型连接测试提示服务暂时不可用，不能据此认为 Key 或代理配置错误。

## 费用与限制

P7 网关对真实模型调用记录提供商返回的 token 用量，并使用填写的价格预留和计算人民币估算费用。累计估算预算上限为 100 元，每次只允许一个并发真实模型调用，失败时的未知费用不会被假定为零。填写的价格并未由系统向提供商核价，因此预算不能保证实际账单不超过 100 元。应按实际提供商价格填写并自行核对账单。

连接测试确认该模型能返回流式文本和用量，不保证所有工具调用行为都正确。当前正式支付与生产认证没有接入，演示令牌不适合作为公网访问控制。停用真实模型会清除进程内 Key；已有真实模型会话在停用后或 API 重启后缺少凭据时会明确失败，不会自动切回模拟模型。

## 接口返回 404

8790 是前端端口，可以在本机通过 `http://127.0.0.1:8790/settings` 使用模型设置。局域网地址的付费操作受 Origin 与管理口令校验，权限拒绝返回 403；404 不表示这项权限限制。

如果前端 `/api/model-settings` 和它代理的 API 地址都返回 404，而 `/api/health` 正常，先确认 API 是否仍运行修改前的代码。普通 API 入口没有自动重载，前端热更新不会更新已启动的 API。到原 API 终端按 Ctrl+C，再在同一终端使用原启动命令重启，保留原环境变量和数据库路径。新的 API 会打印模型管理口令，浏览器刷新后使用该口令。不要为修复路由执行 `db:reset`。

协议和 Base URL 应按提供商接入示例填写：示例调用 `/v1/messages` 时选 Anthropic Messages；调用 `/v1/chat/completions` 时选 OpenAI Chat，Base URL 通常包含 `/v1`。模型名称必须使用提供商实际支持的模型 ID，输入与输出单价分别按其每百万 token 人民币价格填写。

## DeepSeek 官方接口

Anthropic Messages 可使用 `https://api.deepseek.com/anthropic`，OpenAI Chat 可使用 `https://api.deepseek.com`，模型 ID 按[官方文档](https://api-docs.deepseek.com/)填写。DeepSeek [默认开启思考模式](https://api-docs.deepseek.com/guides/thinking_mode)，而当前会话契约不保存或回传推理块；官方域名的两种协议请求因此显式发送 `thinking.type=disabled`，连接测试和后续对话均使用非思考模式。其他提供商不会自动附加此扩展参数。

旧传输实现遇到 Anthropic 思考块会返回 `PROTOCOL`，仅切换接口协议还可能因短测试输出额度耗尽而返回 `TRUNCATED`。修复后重新测试，若 API 自动重载导致管理口令更新，需要填入新口令。此兼容修复通过本地 SDK 流式回归，真实供应商成功连接仍以实际测试结果为准。

## 已有回复但页面空白

SSE 请求 Pending 是长连接正常状态，不等于后台没有返回。浏览器请求压缩时，旧 Next 代理可能缓冲事件；现已给 SSE 响应添加 no-transform。刷新后选择原历史会话即可回放用户消息、助手回复和订单卡片，无需重新调用模型。发送即回显和处理进度的边界及验收见[消息与进度交接](../handoffs/customer-message-progress.md)。处理进度来自公开系统状态和工具动作，不是模型原始推理。
