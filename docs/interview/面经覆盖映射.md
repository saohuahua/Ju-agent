## 图片之外的深追问

| 追问组 | 回答落点 | 必须能说清的反例 |
| --- | --- | --- |
| 模型迁移 | Q16、检索生成扩展 | 接口通不等于工具行为兼容，原运行不偷偷换模型，未知价格不按零计费 |
| DAG 部分失败 | Q17、编排扩展 | D 失败不自动重做已确认 B/C；E 是否降级取决于业务依赖 |
| 抢占与 CAS | Q13 | 租约到期不等于旧进程消失，围栏不能撤销外部付款 |
| 六类恢复 | Q11、Q14、Q15 | 断线、模型重试、只读重试、进程恢复、未知资金和补偿不是同一动作 |
| 评测可靠性 | Q18、Q19 | 模拟用户和 Judge 都会失败，等价正确路径不应误判，零样本无结论 |
| 自主性与规则短路 | Q01、Q04 | 任务完全确定时普通流程更合适，模型价值不能靠削弱规则证明 |
| AI Coding 现场题 | Q23、渐进练习 | 补丁输出不等于成功修改，测试绿不等于需求和目标环境都满足 |

面经覆盖表示已经提供回答材料，不表示用户已经掌握，也不表示所有主题已实现。复练可使用[集中自测](../learning/09-练习与自测/集中自测.md)和[解析](../learning/09-练习与自测/集中自测解析.md)，按答案中缺失的因果关系回读正文。
