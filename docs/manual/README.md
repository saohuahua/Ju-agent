# 有据售后操作手册

本手册对应 2026-09-28 核对的 aftersales 工作区版本。订单和支付渠道使用模拟实现；客户对话可由主管在本机单独启用真实模型。**真实模型对话可用，不表示真实模型评测入口可用。** 当前评测命令只运行离线模式。

## 从哪里开始

| 使用者         | 阅读顺序                                                                                                                         | 完成后应能做什么                         |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- |
| 客户与售后专员 | [业务操作](business/README.md) → [完整案例](business/examples.md)                                                                | 发起售后、补充信息、寄回、接管和核对结果 |
| 主管与管理员   | [管理操作](admin/README.md) → [审批案例](admin/examples.md)                                                                      | 审批、核查执行进度、查政策、管理模型连接 |
| 开发与运维     | [开发接入](devops/development.md) → [运维](devops/operations.md) → [评测](devops/evaluation.md) → [接口示例](devops/examples.md) | 启动、接入、复现、评测、排查及恢复       |

首次使用先由开发人员在项目根目录执行 `pnpm dev:offline`，打开终端打印的工作台地址。首次安装及启动条件见[开发接入](devops/development.md)。左下角“当前身份”可选择客户张伟、客户李娜、售后专员、主管审批。它是演示身份切换，不是注册登录系统。

希望直接验证完整业务时，执行 `node --import tsx docs/manual/devops/demo.ts`。它在新的临时双库中完成两类退款、审批、寄回、重启恢复与备份恢复；不改变日常开发库。具体输入和判据见[完整案例](business/examples.md)。

## 功能覆盖与边界

| 功能                                                     | 对应说明 | 当前入口与边界                                                                   |
| -------------------------------------------------------- | -------- | -------------------------------------------------------------------------------- |
| 客户咨询、选单、补问、历史会话、人工帮助、结束咨询和评价 | 业务操作 | `/workbench`，客户只操作本人记录                                                 |
| 仅退款、退货后退款、寄回及原单进度                       | 完整案例 | 持久离线会话已接入，等待收货不能解释为退款完成                                   |
| 队列搜索、分页、内部备注、人工接管、回复与结案           | 业务操作 | `/console`，专员与主管                                                           |
| 审批、决定后执行结果                                     | 管理操作 | `/approvals`，专员可查看，主管作决定                                             |
| 政策原文、片段及两种检索方案                             | 管理操作 | `/policies`，只读快照，没有上传编辑发布入口                                      |
| 模型连接、停用、健康状态                                 | 管理操作 | `/settings`，配置要求本机主管及管理口令                                          |
| L1、离线 L2、报告、Judge、证据比较                       | 评测专章 | `/eval`、CLI、显式离线 API，网页 L2 禁用                                         |
| 运行列表、事件、工具轨迹、物流注入、旧恢复入口           | 开发接入 | `/runs` 与 `/runs/{runId}`，持久运行由 Worker 恢复                               |
| 运营分析及满意度                                         | 业务操作 | `/analytics`，不在主导航；模拟与评测数据不计入客户运营指标                       |
| 仓库收货、团队代登记寄回                                 | 接口示例 | 内部 API；未提供独立仓库管理页面                                                 |
| 补偿、价保、换货与人工接管回归                           | 评测专章 | 已有领域实现和用例，当前离线客户模型对补偿、价保、换货转人工，不保证聊天自动闭环 |
| 有限双分支调查、检索专项                                 | 评测专章 | 开发专项命令，不是客户侧功能开关                                                 |
| 本地启动、停写备份、迁移恢复、容器部署                   | 运维     | 容器尚未完成本机验收，不能以本地通过替代                                         |

“管理员”在本手册指主管及有主机权限的维护人员。代码没有独立 admin 角色，也没有账号创建、权限编辑、政策发布后台。遇到这些需求应作为新功能提出。
