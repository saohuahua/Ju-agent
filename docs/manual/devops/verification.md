## 发现的旧说明差异

- 旧评测说明为 96 条，网页写死 111 条与 P0 37 条；当前实读和实跑为 124 条、P0 42 条。
- 旧说明称 eval:sim 需要密钥并支持供应商模型参数；当前正式 CLI 只接受离线模式，网页真实 L2 禁用。
- 部分旧学习描述没有完整体现当前 Pass@k 已有实现。本手册以 report.ts 的实际计算为准，与 Pass^k 分开解释。
- 旧 p11-demo.ts 的大额退货在本轮等待审批超时。实查发现商品单价仍为 899 元，即使订单总额改成 6999 元，当前选品退款仍按该商品计算，直接进入待寄回。新手册脚本同步商品明细与实付后通过，没有修改原业务实现或降低审批断言。

上述差异在相关操作章节明确说明。原历史文档和业务代码未在本次任务中批量修改，以免改变已有工作。
