# 售后工作台紧凑布局改造方案

状态：用户已确认实施 代码与页面交互验证已完成

## 目标与范围

面向客服与开发使用者，以用户提供的三栏工单工作台截图为结构参考，提升单屏信息密度和处理效率。主要使用场景为 1920×1080 及以上桌面屏幕。

- 重构工单工作台布局，保留现有业务能力、接口、权限和业务核验规则
- 售后团队后台统一新主题色，其他后台页面不重排布局
- 客户入口不纳入本次主题变更范围
- 不新增通用停止执行能力，不虚构优先级、会员等级等缺失数据
- 未经明确要求不运行项目 build
- 新增代码注释精炼且不含标点

## 现状与参考图差异

当前 CaseWorkspace 已有队列、会话、订单政策依据三栏。执行轨迹在中栏页签，需要迁移至右栏调试视图。已有搜索、状态筛选、加载更多、刷新、内部备注、人工接管、人工回复和结案核验均需保留。

当前数据提供 runId、customerId、status、intent、createdAt、updatedAt 等字段。工单分类使用已有 intent，缺失时显示未识别。不展示无数据来源的优先级、会员资料。工单编号是运行编号，不生成虚假的短编号。

已有恢复运行接口不等同于通用启动或停止执行。是否在工作台暴露某项已有操作，必须核对适用状态与权限。人工接管不能替代停止执行。

## 布局

- 工作台全局导航默认折叠为窄图标栏，可展开，其他页面保持原布局
- 左侧工单队列、中间详情与对话、右侧 Agent 面板
- 两处分隔线可拖动，右栏可以收起，提供键盘可操作的调整方式
- 初始建议左栏 280px，其余宽度中栏占 58%、右栏占 42%，这是待页面验证的实施起点
- 三栏分别滚动，顶部摘要和底部编辑区保持可见
- 正文 14px，通过缩小间距、标签和冗余容器提高密度
- 较窄屏幕保证可访问，不让三栏被强行压缩到无法操作；优先收起导航和右栏

## 左栏

标题单行截断，悬浮可查看全文，中栏完整显示标题。编号、分类、状态、时间直接展示。保留来源标识与客户信息的可访问入口，避免评测会话与客户会话混淆。

保留现有搜索、全部/需关注/处理中筛选、加载更多和刷新能力。统计明确表示已加载数量，不冒充全库总数。列表顺序沿用现有创建时间排序。

首次进入不自动选择工单。搜索或筛选后清空选择。后台刷新保留仍可见的当前工单，当前工单不再可见时显示未选择状态，不跳到另一工单。

## 中栏

- 顶部固定完整标题、编号、状态和客户摘要
- 用户资料及描述可折叠，仅展示现有数据；从首条客户消息提取描述时标明来源
- 对话为主要内容，独立滚动；内部备注保留独立查看入口
- 底部固定回复和备注编辑区，清晰区分对客户可见与内部可见
- 工单处理操作放顶部，低频操作放更多菜单
- 人工接管和回复沿用当前允许状态，不放宽现有权限
- 顶部点击人工结案后，底部编辑区切换为结案摘要，展示核验阻塞项，通过核验后才能提交
- 草稿在当前页面内按身份、工单和编辑用途隔离暂存，切回工单恢复，切换身份清空，刷新不保留
- 提交中的操作绑定原工单，不因切换导致发给另一客户或清空其他工单草稿

## 右栏

提供业务视图和调试视图，首次默认调试视图，记住个人选择。切换视图或收起面板只影响展示，不改变后端执行状态。

业务视图整合订单、政策原文入口、实际处理进度和待办。沿用审批中心入口，不在本次布局改造中另造审批流程。不把工具调用成功直接表述为退款或其他业务已经完成。

调试视图采用时间线呈现真实执行事件，包括可取得的步骤、检索、工具输入输出、结果与错误。参数和结果默认展开，可手动折叠；超长内容局部滚动。阅读历史时暂停自动跟随，提供回到最新入口。汇总统计必须有真实数据来源，未记录的指标不显示为零，不生成截图中的虚构证据校验节点。

执行操作放右栏顶部，但仅展示现有接口、权限和状态支持的动作。不添加无功能的停止按钮。

## 已确认主题

中性白灰为主体，蓝色仅用于链接与主按钮。不要大面积蓝背景、橘色品牌色、棕色文字、渐变或装饰性阴影。通过细边框、小圆角、字重和对齐建立层次。

| 用途               | 色值              |
| ------------------ | ----------------- |
| 主面板             | #FFFFFF           |
| 次级背景与客户气泡 | #F7F8FA           |
| 分隔线             | #E5E8EC           |
| 输入边界           | #C7CED6           |
| 标题与正文         | #20252B           |
| 次级文字           | #626C78           |
| 工单选中背景       | #F0F1F3           |
| 主按钮与链接       | #315F80           |
| 成功文字与背景     | #376744 / #EDF6EE |
| 警告文字与背景     | #805E20 / #FBF5E6 |
| 失败文字与背景     | #A13E38 / #FBEFEE |

处理中标签采用灰底深灰字。页签选中使用深灰字及灰色下划线。语义颜色只用于小面积状态提示。不可只依靠颜色表达选中和异常。

这些色值为根据用户参考图设计的提案，不是截图精确取色。样张位于 artifacts/workspace-color-proposal.html 和同名 PNG，样张内容仅用于展示配色，不代表真实业务数据或最终布局。

## 实施与验收

1. 检查并保留用户现有未提交修改，核对局部目录指令
2. 分离团队后台和客户入口主题作用域，避免全局变量误改客户界面
3. 实现工作台布局迁移，复用现有接口与真实事件数据
4. 验证列表搜索筛选、工单切换、草稿隔离、备注回复、结案阻塞、面板折叠及拖动
5. 验证空态、加载失败、事件断线、长标题、长参数、权限差异与滚动行为
6. 在主桌面尺寸检查视觉效果，并确认较窄屏幕仍可操作
7. 运行与变更相关的类型检查及必要测试，不默认执行 build

本次已实施工作台布局与后台主题调整，未新增接口。类型检查、ESLint 和原有 69 项前端测试通过。浏览器验证覆盖工单切换与草稿恢复、模拟异步提交、身份隔离、视图记忆、搜索、面板收起、键盘与指针分栏调整，以及桌面和窄屏布局。未运行 build，未提交真实业务操作。

后续若需要扩展接口或改变业务语义，应提出具体冲突后再确认，不能自行扩大范围。
