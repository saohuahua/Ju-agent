## 从正文走到函数内部

1. **先看业务问题**，确定代码正在检查身份、保存方案、取得资格还是确认结果。
2. **点击片段上方的源码链接**，按函数名继续读完整上下文；行号是本次更新时的位置，后续代码移动时优先搜索符号。
3. **沿函数内部注释追分支**，核对为什么拒绝、为什么复用原记录、哪些状态一起改变。
4. **回到页面判断含义**，区分受理、审批、寄回、收货、资金成功和人工结案。

源码注释重点解释业务目的、前置条件、状态变化和异常边界。注释不代替运行验证，已有测试与本次检查范围见[后端基础代码与注释复核](../维护与证据/后端基础代码与注释复核.md)。
