# 导学：有据售后 AfterSales Copilot

这套材料面向熟悉前端与 TypeScript、需要补齐后端和 Agent 工程基础的开发者。学习重点是解释设计如何形成、模块怎样协作，以及哪些结果有项目证据支撑。最终目标是能够重建精简核心闭环，而不是记住技术名词。

## 阅读方式

按章节顺序阅读。每章先看阅读前提和实现思路，再看必要机制、故障案例、源码参考与证据。实现思路应足以帮助读者画出核心流程；源码用于核对真实细节，不要求先逐行读完整仓库。

前端常规语法不重复教学，后端基础随章节补齐。若某文件或原理看不懂，请结合具体路径继续追问 AI；导学提供阅读路线，正文解释实现思路，不逐行翻译整个仓库。22 章正文与配套材料均已落盘，源码、图示和链接的检查范围见[编写与复核记录](编写与复核记录.md)。

## 把阅读变成可复现与可讲述的能力

完成正文后进入[八阶段渐进重建练习](渐进重建练习.md)，在独立目录实现小闭环。练习提供输入、验收与参考设计，本次未替读者完成整套教学工程。只想先观察完整业务时，按[本地离线演示手册](../runbooks/p11-local-offline-demo.md)运行现有脚本，再回正文解释每个状态。

随后完成[44 道集中自测](集中自测.md)，再读[解析](集中自测解析.md)。[面经](../interview/面经-有据售后.md)包含 24 道主问、逐题两层追问和源码索引；[40 题覆盖映射](../interview/面经覆盖映射.md)区分实证、扩展与待核实，不能把题目覆盖误认为产品能力覆盖。

框架、MCP／Skill、通用 DAG 和长期记忆见[编排扩展](扩展-编排协议与记忆.md)；向量、融合、重排、知识发布和模型切换见[检索与迁移扩展](扩展-检索生成与模型迁移.md)。这两篇是扩展设计，不作为项目实战成果。

## 证据口径

源码说明当前实现，实验说明特定版本与条件下验证过什么，计划说明预期。离线测试与 L1 不作为真实模型效果，历史真实模型成绩不代表当前版本。个人贡献待本人核实，P10 容器待验收与 P5 真实模型锁定状态不因文档编写改变。

引用数字前查[核心结论与证据索引](核心结论与证据索引.md)，准备简历前查[事实与贡献摘要](../interview/简历事实摘要.md)。读完后应能讲清完整请求、事务受理、审批绑定、资金未知、租约抢占、SSE 补发、模型预算、有限分支及评测边界；这些是理解目标，不是对个人已掌握程度的自动认证。
