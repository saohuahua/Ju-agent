# 前端读者视角复读记录

日期：2026-09-28。目标读者熟悉前端与 TypeScript，后端基础较弱，略懂 Agent。本轮检查原 22 章与新增业务篇的阅读衔接、正文推理、案例和练习，并针对当前源码核对行为冲突。采用代入读者视角的编辑审查，不是真实新手盲测，也不以作者能理解作为读者必然掌握的证据。

## 复读判断

原稿已经有业务内容，但前置知识安排仍偏向熟悉后端的人：部分术语先使用后解释，导学让读者过早进入架构；正常案例缺少固定金额与记录快照；旧技术章节和新业务篇之间还存在版本行为差异。这些问题会让读者“每段似乎懂了，连起来仍说不清”。本轮据此直接修订，没有仅追加笼统的阅读建议。

## 发现与修订

| 发现 | 对读者的影响 | 已修订位置与方式 |
| --- | --- | --- |
| 开篇使用领域、持久化、渠道、投影而未及时定义 | 需要靠后端经验猜含义 | 第 01 章在首次使用附近解释，并明确模拟渠道 |
| Worker、命令、任务、轮次容易混用 | 把一次请求、一轮模型和整笔售后当同一件事 | 导学与第 02 章解释职责，明确不是浏览器 Web Worker |
| 仓储、服务、注入被视为已知概念 | 打开多包源码仍不知道谁负责什么 | 第 03 章用普通对象与调用关系解释 |
| 第 06 章要求已有 SQL 基础 | 前一章无法提供完整前置 | 第 05 章补表行对象与连接，第 06 章解释 SELECT、UPDATE、WHERE、参数及 changes |
| 文件夹顺序与实际学习依赖不同 | 频繁跳转，业务被架构术语打断 | 导学改六阶段路径，架构后置，B10 在退款主线后立即回到页面 |
| 英文状态缺少就近业务含义 | 看见 completed 就误判全部完成 | B02 增加对象、状态、中文含义与下一位行动者对照 |
| 正常案例主要描述机制 | 难追踪同一笔钱和同一张记录 | B04 增加 299 元仅退款的身份与观察表，B05 增加 320 元退货并排状态表 |
| 新版 conclude 与旧版被统一称为结束 | 不理解答复后为何仍能继续聊天 | 第 09、10 章区分答复、补问和会话结束，同步自测及图 09 |

| 未知资金在不同表中的名称不清 | 误以为每张表必须都有 unknown | B04 按当前持久主线明确 sending、unknown、executing 与 needs_confirmation 的组合 |

| 原 SVG 连线穿过说明或箭头被遮挡 | 容易误读控制流 | 调整图 09 和图 12 的线路，重新浏览器渲染 |

## 按具体问题检查解释是否闭合

| 推导问题 | 正文现在提供的依据 | 核对结果 |
| --- | --- | --- |
| HTTP 202 后为何还没有退款单 | B04 区分输入命令与业务建单的观察点 | 能定位已保存与尚未发生的事实 |
| 299 元在哪一步确定，重试会否换金额 | B03 的金额来源、B04 的固定身份和原方案 | 可以沿同一退款推导，不需要猜模型输出 |
| 寄回后为何仍不退钱 | B05 的并排状态和下一位行动者 | 能指出缺少操作员收货，而不是只说后台 loading |
| approved 是否足以结案 | B06 的授权交接、B07 的逐资源白名单 | 能区分审批结束与资金结束 |
| 回答结束后还能不能继续问 | 第 09 章版本表及第 10 章等待原因 | 能区分补问等待和普通咨询等待 |
| 模型说成功、数据库仍未知时显示什么 | B10 的快照依据和优先级 | 有可追溯的展示规则 |
| 读源码从哪里开始 | B04 增加方法名搜索及对应问题 | 可按一个问题逐站阅读，无需先通读大文件 |

这些是基于给定事实的纸面推演和源码核对，不是新增运行结果。原 23 道业务练习和 44 道技术自测保留，修改对应解析以消除歧义，不用更高题数冒充更好学习效果。

## 验证与剩余边界

文档链接、锚点、章节结构和题目编号由现有检查脚本复核。本轮变动的图 09、图 12 使用已安装 Chrome 无头渲染，检查文字边界并查看截图；未重新执行业务流程、未 build、未调用真实模型或资金。图示仍未经过 Typora 实际显示验证。

检查结果见[文档检查](业务篇文档检查.json)和[图示定向复核](图示定向复核.json)。此前 66 个无关旧文档断链保留在报告中，未归为本次通过项。旧 P11 复核中的 Top3 等描述保留历史日期，本轮现行说明以对应正文和当前源码为准。

修订后的教学目标是让读者能沿固定案例解释流程、状态和设计理由；独立实现仍需要完成练习，不能由一次代入复读保证。后续若实际阅读仍卡住，应记录具体章节与无法回答的问题，在该处补足解释，而不是继续堆叠无关章节。
