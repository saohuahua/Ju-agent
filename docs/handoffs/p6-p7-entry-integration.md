# P6 本地集成与 P7 正式评测入口交接

日期：2026-09-26

本轮保留原工作树及两个 P7 并行模块。未修改费用报告专属源码、测试或交接文件，未变更 P7 账本字段、评测身份编码和美元费用字段。未 build、未提交 Git、未读取密钥、未调用真实模型或真实资金渠道，未启停原有 8787 或 8790 服务。P5 保持锁定。

## P6 本轮收口范围

已关闭上一轮记录的等待阶段执行权与收货命令绑定缺口。

- 正式迁移装配执行权表，历史未知资金保持冻结，三类旧业务服务注入同库执行权守卫
- 审批受理事务内完成等待阶段接管，原退款 holder 绑定原审批命令
- 收货先验证原审批、业务、客户、金额及寄回前置，再在同事务将 ready 且无 token 的 holder 转绑到收货命令
- sending、unknown、历史 unassigned 不能转绑或取得第二个发送许可
- DurableBusiness 只认领带 business-accepted 接管凭据的任务，不扫描消费历史运行中意图
- 审批决定走正式 HTTP 事务意图，显式持久模式不再启动旧审批后台恢复
- 寄回登记和收货接入正式 HTTP；收货任务可从原审批进度追溯，未知资金显示待核验
- 终态结果只投影一次到原动作结果与客户事件，等待任务完成不表示退款成功
- 未消费售后审批过期可终止原退款，未知或已接管许可不因过期释放

正式入口使用 `P6_BUSINESS_MODE=simulation` 显式启用，`P6_PAYMENT_SIMULATOR_URL` 仅允许 `http://127.0.0.1` 模拟渠道。该模式禁止构造真实主模型，启动普通只读持久会话与业务 Worker，并在进程关闭时等待有界任务退出。没有在用户演示库实际启用此模式。

新增接口 `POST /api/operations/return-shipment` 接受 returnNo 和 trackingNo，限操作员或主管；原 `POST /api/operations/receive-goods` 在持久模式返回 accepted 和 taskId。已接管业务不能再通过旧消息、恢复或物流触发路径驱动旧 Agent。

本轮验收对象为普通只读会话加已有审批及收货的本地模拟链路。自动批准资金工作流仍沿用带执行权守卫的旧路径；普通持久会话尚不创建任意资金方案。未声明 P6 所有业务已全面迁移、生产可用、Docker 已验证或真实渠道已接通。

## P7 正式入口

`pnpm eval` 与 `pnpm eval:sim` 现在统一使用 P7 工厂、运行快照和共享累计账本。三角色每个用例重复轮次只创建一组模型；套件不再重跑整条用例来重试供应商故障，attempt 完全交给网关。

CLI 不再读取环境密钥，默认数据库为 `data/eval-p7.db`。支持 `--db`、`--output`、`--experiment-id`、`--repeat`、`--case`、`--category`，L2 另支持 `--sample`。真实模型参数直接拒绝。用例或角色模型配置只允许通过受信 roles 解析器提供，HTTP 不接受裸模型覆盖。

L1 使用离线完整工具目录回放弱模型脚本，以继续验证领域越权防线。这个测试目录策略只存在于 L1 回放包装，L2 保留 Agent 动态目录，P7 协议保护未放宽。所有离线费用和 usage 都是明确的人工测试值。

L2 使用真实 UserSimulator、主循环和 judgeTranscript 消费离线协议。离线 Judge 对主观判据返回未评估失败，不将脚本当作真实质量判定，不输出统计采样置信区间。既有 gatePassed 仍表示 P0 门禁，不能用它代替所有用例通过；附件保留每个失败及模式标记。模型异常即使被消费者捕获，也会强制记入执行失败并使门禁失败。

身份继续使用原 p7-eval-v1 JSON 元组；未增加调用序号恢复，重建同一身份会被原唯一约束拒绝。计划重复轮次不是故障重试。取消信号传入三个角色，未知费用不会被释放。

## 费用报告接入

复核并复跑并行交付的 15 项费用报告测试，通过原 `readP7CostReport` 读取同一账本，不另写计价或汇总算法。

原 EvalReport 与美元字段不变，独立 `evidence` 附件包含：

- experimentId、caseId、repeat、三角色模型子运行与业务 runId 关联
- 各用例执行结果及失败明细，包含没有新增账本行的拒绝原因
- 当前实验费用 selection 与完整共享 scope 占用
- settled 实耗、unknown 预占、held 预占、blocked、未归因与异常身份

CLI 同时输出 `.json`、`.md` 和 `.evidence.json`。数据库新增 `eval_budget_evidence` 保存报告关联；它不是预算表，业务夹具重置不清除此附件或 P7 账本。

内部接口 `GET /api/eval/reports/:reportId/evidence` 返回已保存附件，客户身份返回 403。L2 HTTP 需显式传入 `mode: simulation`，可轮询原任务接口或调用 `POST /api/eval/sim-tasks/:taskId/cancel`。未显式选择模拟时，即使环境存在密钥也拒绝启动 L2。
