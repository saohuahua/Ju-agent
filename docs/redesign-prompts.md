# AfterSales Copilot 原型重设计 Prompt 包（v0.dev 版）

> 目标工具：v0.dev（Next.js + React + Tailwind）
> 视觉方向：浅色专业风（企业级 SaaS）
> 用途：把现有功能型 UI 升级为一套可展示、可放进简历的作品级界面

## 使用说明

1. **先喂「0. 全局设计系统」**，让 v0 记住整套视觉语言与组件规范。
2. **再逐屏喂 1–6 的页面 prompt**，每屏开头都写了「沿用上面的设计系统」。
3. 建议顺序：框架 → 会话工作台 → 审批中心 → 运行记录 → 运行详情 → 评测看板。
4. 生成后如果想统一微调，追加一句话：`把 X 改成 Y`，v0 会在同一套设计系统内更新。

## 设计叙事（为什么这么设计）

这个项目的差异化**不是「聊天机器人」，而是「让 Agent 在有副作用的业务里安全工作，并用数据证明它做对了」**。所以界面必须把「治理与评测」推到台前，而不是一个娱乐化的聊天框：

- **会话工作台**是客户视角，但旁边始终挂着「工具轨迹 + 审批卡 + SSE 连接状态」，让安全治理层可见。
- **审批中心 / 运行详情 / 评测看板**才是真正的核心，突出「可审计、可恢复、可评测」。
- 视觉上要「可信赖」：克制的配色、清晰的证据字段、无花哨动效。

## 0. 全局设计系统（先喂这一条）

```
你是一名资深产品设计师与前端工程师。请为「AfterSales Copilot —— 可评测、可恢复的电商售后 Agent 平台」建立一套完整的浅色专业风设计系统，并用 Next.js + Tailwind 输出可运行的 React 组件。

【产品定位】
这不是一个客服聊天机器人，而是一个面向电商售后（退换货/退款）的业务 Agent 平台，核心命题是：让 Agent 在有副作用（资金动作）的业务里安全工作，并用数据证明它做对了。设计必须体现「可信赖、可审计、可恢复、可评测」的技术治理气质，而不是娱乐化的聊天界面。

【视觉基调】
- 浅色、专业、企业级 SaaS，干净留白，克制装饰，不要花哨渐变和动效
- 主色 indigo/blue（可信赖感），进行中用 sky，成功 emerald，失败 red，等待 amber，升级 purple，审批/风险 orange
- 中性色 slate：页面背景 slate-50，卡片纯白 + slate-200 边框，正文 slate-900，次要 slate-500
- 圆角统一：卡片/输入框 12px，徽章/按钮 6px；阴影轻量，仅悬浮层级使用
- 中文字体：系统无衬线（PingFang SC / Microsoft YaHei / system-ui）；ID、金额、工具轨迹等「技术证据」字段用等宽字体 mono
- 状态徽章统一为「浅色底 + 深色文字 + 细边框」的 pill（例：emerald-50 底 / emerald-700 字 / emerald-200 边）
- 信息密度适中：金额、状态、指标一眼可见，次要信息降噪

【核心组件规范】
- StatusBadge：圆角 pill，浅底深字细边，状态 → 已创建(slate) / 执行中(sky) / 等待补充信息(amber) / 等待审批(orange) / 已完成(emerald) / 失败(red) / 已取消(slate) / 已升级人工(purple)
- ToolCard：工具调用证据卡，展示工具名、尝试次数、耗时、结果摘要、错误码；成功/失败用不同浅色底，忠实呈现不美化
- ApprovalCard：高风险审批卡，橙色系强调，金额醒目，批准(emerald)/拒绝(red)按钮
- MetricTile：评测指标卡，小字标签 + 大号数值
- 表格：白底卡片包裹，表头 slate-50，行 hover 浅灰，ID 用等宽字体
- 空状态：虚线边框卡片 + 居中提示文案，不允许空白
- 所有按钮在请求期间 disabled 防重复提交；错误信息用红色浅底条展示

【布局】
- 左侧固定侧边栏（约 220px）承载导航与演示身份切换
- 主区顶部标题栏 + 内容区 max-w 居中（对话页窄、列表/看板页宽）
- 中文界面文案，金额分转元统一格式化（¥12,345.67 样式）
```

```
  - 订单 SO-2026-0009 没发货 申请退款

【消息流】
- 用户消息：右对齐，主色底 + 白字圆角气泡
- 助手消息：左对齐，白底卡片 + slate-200 边框
- 系统提示：居中灰色小字
- 流式输出时末尾加一个跳动的光标 ▍

- 每条工具调用一张 ToolCard，展示工具名（等宽）、尝试次数、耗时、结果摘要、状态徽章，忠实呈现

【审批区】
- 高风险时插入 ApprovalCard：橙色卡片「需要人工审批」+ 金额醒目 + 原因 + 资源号，客户侧显示「等待主管在审批中心处理」

【底部输入区】
- 输入框 + 「发送」按钮，等待输入时按钮可点、进行中 disabled，placeholder 随状态变化（请描述售后需求 / 请补充信息 / 会话进行中）

输出可运行的 Next.js 页面代码。
```
